# Komari Dockerfile for Choreo

1.6.2-fix1

# Releases

## 主要更新内容

- **终端控制协议**：终端 WebSocket 改用「二进制帧传终端内容 + 文本帧传控制消息」的双通道设计，新增 `heartbeat`、`resize`、`terminate`、`abort`、`assigned`、`ready` 等消息类型。控制消息不会污染终端缓冲区，且两端都会忽略未知消息，新增类型无需客户端改代码。服务端与 Agent 均已实现。
- **终端会话可恢复**：浏览器或 Agent 意外断开后，会话在服务端保留 5 分钟，可用同一 `request_id` 重连续接，期间自动向在线一方发送 `abort` 等待重连；超时才发送 `terminate` 并清理。新增 `admin:listRecoverableTerminalSessions` 与 `admin:terminateTerminalSessions` 接口，用于列出和终止等待恢复的会话。
- **终端自由分屏**：终端工作区支持任意方向、任意层级的窗格分割，可自由拖动调整布局，标签与分屏结构相互独立。
- **终端、编辑器与文件管理体验优化**：完善终端设置对话框、背景媒体、上传进度展示，优化编辑器内终端面板与远程文件树的交互；终端默认关闭 EOL 转换，避免输出出现多余回车。
- **全面增强管理员日志**：登录/登出（含 User-Agent）、2FA 启用/禁用、OAuth 绑定/解绑、用户编辑（含字段变更明细）、客户端增删改、插件与主题安装更新、备份下载/上传、数据库维护、文件传输、通知发送等操作均记录操作者 IP 与 UUID；同一终端会话只写一条审计记录，重连、挂起、结束时原地更新时长、重连次数与结束原因。连接串凭据等敏感值自动脱敏。
- **日志筛选查询**：管理端日志接口新增 `msg_type` 与 `q` 参数，支持按消息类型及关键词（内容、IP、UUID）筛选。
- **Agent 可被服务器读取启动参数**：服务器可通过协议获取 Agent 的完整启动配置，便于在线排查部署问题。
- **Agent 支持远程切换版本**：可在管理端请求 Agent 切换到指定版本线（稳定版或快照版），切换完成自动重启生效。
- **前端性能优化**：重构构建配置，移除 `vite-plugin-pages` 改为静态路由，优化代码分包、首屏加载与 PWA 缓存策略，显著减小打包体积并改善渲染性能。
- **后台视觉与动效更新**：新增全局动画设计，统一后台页面的过渡与操作反馈，优化整体视觉表现。

## Bug修复

- 修复主题解压时目录权限沿用压缩包内的 `0664`（缺少执行位）导致后续写入文件失败、市场安装主题报 `permission denied` 的问题，目录统一以 `0755` 创建。
- 修复自动续费月末到期日溢出问题：按 `AddDate` 计算会把 10 月 31 日续费成 12 月 1 日，现改为保持在目标月份内（如 1 月 31 日 → 2 月 28/29 日）。
- 修复 GPU 温度字段被截断为整数的问题，服务端与 Agent 均改为保留小数精度（如 `55.25°C`）。
- 修复备份白名单中 `plguin-data/` 拼写错误，更正为 `plugin-data/`。
- 修复插件设置页左右栏错位及空状态提示重复的问题，并补充「请在左侧选择要配置的插件」引导。
- 修复 Linux 下 LXC 容器上报的 uptime 为宿主机数值的问题，改为读取 `/proc/uptime`。
- 修复 Windows 安装脚本在用户名或路径含空格时安装失败的问题（UAC 提权后自动重新转义参数，nssm 服务路径不再写入多余引号）。相关 [#118](https://github.com/komari-monitor/komari-agent/issues/118)、[komari#655](https://github.com/komari-monitor/komari/issues/655)
- 静态资源写入失败时补充明确告警，便于定位权限问题。

## 其他

- WebSocket 连接改为自行管理在线状态，避免 HTTP 上报与连接生命周期互相干扰。
- 非 API 请求（静态资源、前端页面）的 2xx/304 响应不再写入请求日志，减少日志噪音；异常响应与 API 请求仍完整记录。
- 删除正在使用的主题前增加二次确认提示。
- 允许 Ping 检测任务留空，不再强制要求填写目标。
- 新增 CI 测试工作流，包含 `go vet`、单元测试、重复运行隔离测试、race detector 与覆盖率报告；清理部分冗余或易冲突的测试用例。
- 同步多语言翻译，补充终端、日志与分屏相关文案。
